## 构建个人AI工作站

### 你需要什么？

- 一台电脑（Windows/Mac/Linux都行）
- Python 3.9+（没有的话去 python.org 下载）
- DeepSeek API Key（去 deepseek.com 注册，有免费额度）

### 第一步：下载代码

**方式1：直接下载ZIP**
1. 打开 https://github.com/tsingxuanhan/xuan-hub
2. 点击绿色的 "Code" 按钮
3. 选择 "Download ZIP"
4. 解压到你喜欢的目录

**方式2：用Git克隆（推荐）**
```bash
git clone https://github.com/tsingxuanhan/xuan-hub.git
cd xuan-hub
```

### 第二步：安装依赖

打开终端（Windows用CMD或PowerShell，Mac用Terminal）：

```bash
cd xuan-hub
pip install -r requirements.txt
```

主要会安装：
- `requests` — 调用API
- `numpy` — 数值计算
- `torch` — 深度学习（可选，只用ML模型时需要）

### 第三步：配置API Key

创建 `.env` 文件（或在终端设置环境变量）：

```bash
export DEEPSEEK_API_KEY="sk-你的key"
export DEEPSEEK_ENDPOINT="https://api.deepseek.com"
```

**Windows用户**：
```cmd
set DEEPSEEK_API_KEY=sk-你的key
set DEEPSEEK_ENDPOINT=https://api.deepseek.com
```

### 第四步：启动工作站

```bash
python quickstart.py
```

看到提示 "AI Workstation Ready" 就成功了。

### 第五步：打开控制面板

```bash
# 方式1：直接用浏览器打开
open control-panel/index.html  # Mac
start control-panel/index.html  # Windows
xdg-open control-panel/index.html  # Linux

# 方式2：启动本地服务器
python -m http.server 8080
# 然后访问 http://localhost:8080/control-panel/index.html
```

你会看到液态玻璃风格的控制面板，显示4个Agent的状态。

## 自建知识库

### 你需要什么？

- xuan-hub 代码（参考上面的安装步骤）
- 你的文档（PDF/Word/TXT/Markdown都行）

### 第一步：准备文档

把你的文档放到一个目录，比如 `my_docs/`：

```
my_docs/
├── 论文1.pdf
├── 论文2.pdf
├── 笔记.md
├── 实验数据.csv
└── ...
```

### 第二步：导入知识库

```python
from memory import PersistentVectorStore
from vector_memory import NGramTFIDFProvider

# 创建知识库
provider = NGramTFIDFProvider()
memory = PersistentVectorStore(provider=provider, persist_path="my_knowledge.json")

# 批量导入文档
import os
for file in os.listdir("my_docs"):
    with open(f"my_docs/{file}", "r") as f:
        content = f.read()
    memory.add(content, metadata={"source": file})

print(f"已导入 {len(memory)} 条知识")
```

### 第三步：语义搜索

```python
# 不是关键词匹配，是理解意思
results = memory.search("混凝土开裂原因", top_k=5)

for r in results:
    print(f"[{r.metadata['source']}] {r.text[:100]}...")
```

**示例场景**：

假设你导入了100篇论文：

```
> 搜索 "GGBS对强度的影响"

找到相关段落：
[论文3.pdf] "矿渣粉掺量30%时，28天强度提升15%..."
[论文7.pdf] "GGBS的活性指数与细度相关..."
[笔记.md] "矿渣粉越细，早期强度越高..."
```

注意：你搜索的是"GGBS"，但匹配到了"矿渣粉"——这就是语义搜索的威力。

### 第四步：持久化保存

知识库会自动保存到 `my_knowledge.json`，下次打开直接用：

```python
# 加载已有知识库
memory = PersistentVectorStore.load("my_knowledge.json")

# 继续添加
memory.add("新的知识...")

# 搜索
results = memory.search("...")
```

### 进阶用法

**多知识库管理**：

```python
# 为不同主题建不同知识库
cement_kb = PersistentVectorStore(persist_path="cement.json")
concrete_kb = PersistentVectorStore(persist_path="concrete.json")

# 搜索时指定知识库
results = cement_kb.search("碱激发")
```

**元数据过滤**：

```python
# 只搜索某篇论文的内容
results = memory.search("强度", filter={"source": "论文3.pdf"})

# 只搜索最近的笔记
results = memory.search("实验", filter={"date": "2024-06"})
```

## 材料科学研究

### 你需要什么？

- materials-ai-kit 代码
- Python 3.9+
- PyTorch（`pip install torch`）

### 安装

```bash
git clone https://github.com/tsingxuanhan/materials-ai-kit.git
cd materials-ai-kit
pip install -r requirements.txt
```

### 场景1：预测强度

```python
from models.property_predictor import PropertyPredictor

model = PropertyPredictor()

# 你的配方
composition = {
    "cement": 450,      # 水泥 kg/m³
    "ggbs": 150,        # 矿渣粉
    "fly_ash": 100,     # 粉煤灰
    "water": 180,       # 水
    "superplasticizer": 5
}

result = model.predict(composition)
print(f"28天抗压强度: {result.strength_28d:.1f} ± {result.confidence:.1f} MPa")
```

### 场景2：从早期强度预测长期性能

```python
from models.lstm_model import LSTMForwardModel

model = LSTMForwardModel()

# 你只测了3天和7天
early_strength = [15.2, 28.5]

# 预测完整曲线
curve = model.predict_curve(early_strength)
print(f"预测28天强度: {curve[2]:.1f} MPa")
print(f"预测90天强度: {curve[4]:.1f} MPa")
```

### 场景3：优化配方

```python
from models.composition_optimizer import CompositionOptimizer

optimizer = CompositionOptimizer()

# 目标：强度40MPa，碳排放最低
target = {
    "strength_28d": 40,
    "minimize": "carbon"
}

# 约束：成本≤500元/m³
constraints = {
    "cost_max": 500
}

optimal = optimizer.optimize(target, constraints)
print(f"最优配方: 水泥{optimal.cement}kg, 矿渣{optimal.ggbs}kg...")
print(f"碳排放: {optimal.carbon:.1f} kg CO₂/m³")
```

## 术语表

**Agent**：AI助手，每个Agent有特定职责（如搜索、验证、编码）

**向量记忆**：用语义向量存储知识，支持语义搜索（不是关键词匹配）

**NGram TF-IDF**：一种文本向量化方法，能捕捉子词相似性

**CNN**：卷积神经网络，用于图像和序列数据处理

**LSTM**：长短期记忆网络，用于时间序列预测

**语义搜索**：理解意思的搜索，"矿渣粉"能匹配"GGBS"

**逆向设计**：从目标性能反推配方，而不是试错法

**液态玻璃UI**：一种UI设计风格，半透明、模糊、柔和边框
