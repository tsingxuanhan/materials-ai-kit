# 秋 · 铉枢开源项目指南

> 一份面向所有人的项目说明书。即使你不懂编程，也能读懂。

## 三个仓库

铉枢的开源项目分为三个仓库，各有分工：

| 仓库 | 定位 | 可见性 | 适合谁 |
|------|------|--------|--------|
| [**xuan-hub**](xuan-hub.md) | 核心框架，完整AI工作站 | 私有 | 想看完整实现 |
| [**agent4science**](agent4science.md) | Agent框架，多智能体协作 | 公开 | 想构建AI Agent团队 |
| [**materials-ai-kit**](materials-ai-kit.md) | 建材AI工具包 | 公开 | 材料科学研究者 |

## 能用来做什么？

### 构建个人AI工作站
让AI帮你：
- 搜索文献、整理资料
- 验证信息、交叉核对
- 生成代码、脚本
- 解释专业概念

### 自建知识库
- 把你的文档、笔记喂给AI
- AI用语义理解搜索（不是关键词匹配）
- 越用越聪明，记住你的偏好

### 材料科学研究
- 预测材料性能（强度、耐久性）
- 优化配方设计
- 文献挖掘和分析

## 技术栈

- **语言**: Python 3.9+
- **AI模型**: DeepSeek API / MiMo API（国内可用）
- **向量检索**: 自研NGram TF-IDF（不依赖HuggingFace，国内直接用）
- **UI**: 液态玻璃风格控制面板

## 阅读顺序

1. 先看 [快速开始](快速开始.md) — 5分钟了解整体
2. 再挑你感兴趣的仓库深入：
   - 想搞Agent协作 → agent4science
   - 做材料研究 → materials-ai-kit
   - 想看完整实现 → xuan-hub

## 版本演进

项目从2025年5月至今，经历了7个版本迭代，v5.0进化方案已设计完成。想看完整版本历史，访问 [迭代档案](../iteration/README.md)。

```
v3.1 (3K行) → v3.2 (3.5K行) → v3.3 (4K行) → v4.0 (25K行) → v4.1 (28K行) → v4.2 (32K行) → v4.3 (34K行) → v5.0 (设计完成)
```

**v5.0**：从"知识处理流水线"到"认知体"——补齐认知架构、因果推理、元学习、元认知、Grounding、对齐6个AGI维度，构建认知飞轮。

从13个文件的小框架，长成了82个文件、34000行代码的完整工作站。

## 知识库

项目配套的知识库（位于xuan-hub仓库）：

| 指标 | 数值 |
|------|------|
| **论文总数** | 524篇 |

### 知识库结构

```
知识库_v2/
├── 基础与算法 (65篇)     ← ML/DL基础
├── 模型与工具 (139篇)    ← 网络架构、GNN、LLM等
├── 材料科学 (107篇)      ← 水泥、GNN、性质预测等
├── AGI理论 (142篇)       ← 认知科学、世界模型、因果推理...
└── 跨领域应用 (43篇)     ← 药物、能源、物理仿真等
```

### AGI认知地图

知识库按四层架构组织，支撑框架向通用智能演进：

```
    AI对齐与价值哲学      ← 全局约束
    意识与机器意识        ← 元认知层
    因果/NeSy/自改进/元学习 ← 上层建筑
    AGI理论/认知/世界模型  ← 地基
```

详见：[知识库说明](../知识库_v2/README.md)

## 设计哲学

1. **存思想不存数据** — 不是堆砌信息，而是提炼推理过程中的智慧
2. **纯增量叠加** — 每个版本只新增，不破坏已有功能
3. **国内友好** — 不依赖外网，DeepSeek/MiMo都是国内API
4. **轻量部署** — 3.8GB内存就能跑（笔记本够用了）
